# 图片与截图说明模板

## 1. 音画审校截图

建议文件名：`抽帧总览.png`

建议拼接四到六张画面：首帧、第一处字幕、中段、转场处、尾帧。每张图旁边标注：

```text
第37期｜00:00 首帧｜标题清晰，字幕未越界
第37期｜00:21 中段｜字幕与口播同步
第37期｜01:42 尾帧｜无残留字幕，画面完整
```

Markdown 示例：

```markdown
![第37期抽帧总览](审校/抽帧总览.png)
```

## 2. 发布页截图

建议文件名：`发布页_双封面与章节.png`

截图至少包含：标题、正文、真实话题实体、横竖封面、声明选项和章节保存结果。

说明示例：

```text
图2｜第37期发布页：四个话题均已识别为平台实体，横竖封面已设置，章节已保存
```

## 3. 作品管理页截图

建议文件名：`作品管理页_提交凭证.png`

截图至少包含：作品标题、定时时间和平台状态。状态必须原样记录：`审核中`、`定时发布中` 或 `已发布`。

说明示例：

```text
图3｜第37期作品管理页：标题一致，发布时间为 2026-11-18 14:30，当前状态为审核中
```

## 4. 无法提供真实截图时

可以使用 Mermaid 流程图、界面字段表或截图占位说明，但不要把示意图写成真实平台验收证据。建议占位格式：

```text
[待补截图] 发布页_双封面与章节.png
需核对：横封面、竖封面、章节保存、声明选项、真实话题实体
```
