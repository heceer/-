# 中文考研视频流水线：逐步执行手册

## 一次性准备

### 1. 固定目录和命名

每期使用独立目录，并固定以下子目录：`脚本`、`音频`、`视频`、`封面`、`审校`、`发布`。文件名包含期数，避免把不同期的音频、字幕和封面混用。

### 2. 验证 GPT-SoVITS

```powershell
Set-Location 'D:\项目\GPT-SoVITS'
& .\runtime\python.exe .\launch_web_hidden.py inference --check
```

确认推理页端口、`/config` 响应和模型路径正确后，再开始批量合成。端口被占用时，先确认占用页面是不是 GPT-SoVITS，不要仅凭浏览器能打开就判断正常。

### 3. 固定配音参数

每期记录以下参数：

```json
{
  "language": "all_zh",
  "gpt": "GPT_SoVITS/pretrained_models/s1v3.ckpt",
  "sovits": "GPT_SoVITS/pretrained_models/v2Pro/s2Gv2ProPlus.pth",
  "speed": 1.15,
  "split": "cut2",
  "batch_size": 1,
  "parallel_infer": false
}
```

## 单期生产

### 1. 准备脚本

脚本应包含标题、正文、逐镜文案、目标时长和分镜顺序。先清理英文缩写、URL、拉丁字母和不可读公式，再进入配音。

### 2. 生成逐镜配音

按 scene 拆分，每段约五十字；每个 scene 保存独立 WAV，同时保存完整口播 WAV。scene 边界必须从实际 WAV 样本数计算，不能用估算秒数。

### 3. 绑定画面和字幕

用正式分镜图、逐镜音频和实际音频时序生成视频。字幕使用白字黑框、画面下方、无句号，并检查中文可读性。

### 4. 做音画审校

至少检查完整解码、音轨存在、实际时长、字幕数量、scene 边界、首中尾帧、音频滞后和字幕亮度。失败时回到音频或字幕阶段修复，再重新导出。

### 5. 生成发布任务

发布任务需要填写视频、横封面、竖封面、复核 JSON、正文、话题和北京时间。正文不得含英文、URL或句号。

## 发布操作

1. 打开已登录的抖音创作者中心专用标签页。
2. 上传视频并等待上传完成。
3. 填写任务 JSON 中的标题和正文。
4. 逐字输入话题，每个话题后输入空格，并确认它变成平台真实实体。
5. 在同一封面弹窗中设置横封面和竖封面。
6. 选择“无需添加自主声明”。
7. 选择“智能生成”章节并点击保存。
8. 设置绝对北京时间，选择定时发布。
9. 本地把状态改为 `提交待确认`，只点击一次发布。
10. 进入作品管理页，核对标题、时间和状态并截图。

## 恢复规则

- 状态为 `提交待确认` 时，先查作品管理，禁止再次点击发布。
- 作品已经存在时，更新本地任务记录，不重传、不重发。
- 仍在编辑页时，只补最后一个缺失步骤。
- 连续两次无法判断页面状态、标题或时长不一致时，停止批量操作并记录。

## 自动化和人工验收边界

本地脚本可以检查路径、视频哈希、中文字符、话题数量和时间格式；试听音色、观看字幕、确认平台真实话题、封面检测和作品管理页状态必须人工核验。
