# 抖音发布设置与可恢复流程

## 单期任务

任务 JSON 记录本地输入和外部状态，推荐字段见 `templates/publish-task.json`。状态流转：

```text
待上传 → 编辑中 → 提交待确认 → 已确认
                         └→ 需恢复
```

`已确认` 只表示作品管理页已有对应条目，不代表已经通过审核或已经公开。

## 页面设置

1. 进入已登录的抖音创作者中心，使用内置浏览器专用标签
2. 上传视频并确认上传完成
3. 填标题和正文；正文只能使用任务 JSON 中的版本
4. 话题逐字输入，**每个话题后输入空格**；最后读取真实话题实体，不接受只显示为普通文本的 `#文字`
5. 同一封面弹窗中上传横封面和竖封面，确认检测通过
6. 自主声明选择“无需添加自主声明”
7. 视频章节选择“智能生成”，生成后点击保存；保存条数写回任务记录
8. 位置和关联热点按任务清单处理；默认留空
9. 选择“定时发布”，填写完整北京时间并移出焦点
10. 集中核对标题、正文、话题实体、双封面、声明、章节、位置热点和时间
11. 本地先写 `提交待确认`，只点击一次“发布”
12. 等待跳转作品管理；列表旧时刷新一次，核对标题、时间、状态并截图

## 时间规则

使用绝对时间 `YYYY-MM-DD HH:mm` 和 `Asia/Shanghai`，不要只写“明天中午”。发布前确认平台当前时间限制；若平台要求至少提前两小时，重新计算并记录用户最终选择。

## 恢复规则

- 断线、超时或用户接管后，先读任务 JSON 和当前管理页
- 如果作品已经存在，更新本地状态，不重传、不重发
- 如果仍在编辑页，读取当前实际 UI，只补缺失步骤
- 如果临时页消失，从本地任务 JSON 恢复输入；无法恢复的平台现场不得伪称保留
- 发布完成后保存管理页截图，截图路径写入任务 JSON

## 话题和封面验收

发布前必须能回答：

- 四个话题是否是真实实体
- 横竖封面是否都已设置
- 作品正文是否和视频主题一致
- 是否意外带入英文或句号
- 时间是否是用户授权的绝对时间
