# 调试与恢复

## 启动故障

先按顺序检查：

1. `D:\01_WORK\01_兼职\GPT-SoVITS\runtime\python.exe` 是否存在
2. `installation_logs/` 中的 `web-hidden-inference.log`、`web-hidden-launcher.log`
3. `9872` 或 `9874` 是否被其他程序占用
4. `http://127.0.0.1:9872/config` 是否返回包含 `get_tts_wav` 的 GPT-SoVITS 配置
5. GPT 与 SoVITS 权重是否来自同一版本族

端口被占但 `/config` 不是 GPT-SoVITS 时，停止猜测页面，先释放端口或换端口。

## 合成故障

- 中文变成奇怪发音：检查文本是否夹杂英文缩写、拉丁字母、未清理的公式和 URL
- 断句不自然：缩短单段文本，使用 `cut2`，不要一次把整期脚本塞给模型
- 语速和视频错位：以实际 WAV 时长重新计算分镜边界，不沿用旧 SRT
- 音色不稳定：固定参考录音、GPT/SoVITS 权重、语速和切分参数后再比较
- 只生成一部分：检查任务清单中每个 scene 的音频文件和 `start_sample/stop_sample`

## 视频和字幕故障

- 先看音频时长、帧数、字幕覆盖率，再看画面
- 最大音频滞后必须为 0 或在项目验收阈值内
- 字幕出现句号、英文、越过画面底部或和音频错位时，回到字幕生成阶段修复，不在抖音发布页补救
- 图片信息量不足时，重新做分镜素材；不要靠重复放大同一张低信息图片掩盖问题

## 浏览器和发布故障

- 页面慢不等于动作没执行。超时后先读取当前页面，再决定是否重试
- 创建或绑定内置浏览器标签后立即保留；每次接续都重新标记保留
- 状态为 `提交待确认` 时先查作品管理，不允许再次点击发布
- 作品管理第一次可能仍显示旧列表，必要时只刷新一次
- 管理页的标题、时间和状态是发布证据；“正在发布”只是中间状态
- 不能把 `审核中`、`定时发布中` 和 `已发布` 写成同一状态

## 停止条件

出现以下任一情况就停止批量操作并记录：

- 连续两次无法判断当前页面状态
- 任务清单与页面标题或视频时长不一致
- 平台已经出现同名作品但时间未核对
- 需要绕过登录、验证码、权限或安全提示
- 需要删除或覆盖用户已有作品
