# 分镜成片与音画审校

## 画面绑定

每期使用 8 幅或实际数量的正式分镜图，按 scene 顺序绑定。首屏要有明确问题或钩子，后续画面提供判断步骤、案例、反例和练习，避免低信息重复图。

使用实际音频 scene 边界切换图片。禁止把 PPT 播放当成最终视频依赖；PPT 可以作为编辑源，但成片必须由正式图片、音频、字幕合成。

## 字幕

- SRT 以实际音频识别和分镜边界生成
- 白字黑框，位于画面下方
- 无句号
- 只允许中文、中文数字和中文标点
- 字幕行宽和停留时间以可读性为准，不追求把整段口播挤在一行

## 验收

保存以下文件：

- 成片 MP4
- 全中文同步字幕 SRT
- 双比例封面
- `第NN期_成片复核.json`
- `第NN期_字幕与画面对齐.json`
- 抽帧总览图或等价可视证据

复核至少包含：完整视频解码、音轨存在、实际时长、字幕数量、每个 scene 的边界、首中尾帧字幕状态、音频滞后，以及字幕亮度或可读性抽样。

样例验收字段：

```json
{
  "episode": 37,
  "seconds": 107.2,
  "subtitles": 56,
  "max_audio_lag_ms": 0.0,
  "max_sampled_caption_luma_error": 1.298,
  "known_omissions": []
}
```

如果失败，回到音频或字幕生成阶段修复，再重新导出并重验；不要只在发布页修改文案。
